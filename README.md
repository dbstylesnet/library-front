# Library Front-end
The app uses React Router (react-router-dom) for navigation and synchronizes UI state with the URL. Pagination state is reflected in the query string (e.g., /?p={page_number}), allowing users to share URLs and return directly to specific result pages. 

## Tech stack
* React with functional components and Hooks
* REST API for data retrieval and server-side filtering
* React-Bootstrap for UI components and responsive layout

![Screenshot showing project](https://github.com/dbstylesnet/books-api-front/blob/main-functionality/screenshot.png)

## In order to start project locally:

### `npm install`
Resolve packages

### `npm start`
Runs the app in the development mode.<br />
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
